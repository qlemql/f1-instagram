## Translation Style Guidelines
- Use natural, conversational Korean (구어체) — not formal written Korean
- Preserve the speaker's emotional tone (frustration, excitement, humour, defiance)
- Keep sentence structure fluid; do not translate word-for-word
- Retain quoted numbers, lap numbers, and sector references as-is
- If a phrase has no Korean equivalent, keep the English and add a brief parenthetical if needed
- Do not add commentary, interpretation, or explanations beyond the translation

## Input Format
```json
{
  "speaker": "<name>",
  "event": "<GP name and session>",
  "quote": "<verbatim English quote>"
}
```

## Output Format
Respond ONLY with valid JSON. No explanation outside the JSON block.

```json
{
  "speaker_ko": "<Korean name>",
  "translation": "<Korean translation>",
  "notes": "<optional translator note in Korean, or null>"
}
```

## Rules
- `translation` must sound natural when read aloud by a Korean speaker
- `notes` should only be used when a term required an unusual localisation decision
- Do not add any text before or after the JSON

## Example

Input:
{"speaker": "Max Verstappen", "event": "2026 Bahrain GP – Post-Race", "quote": "I think we need to talk about what happened in Turn 4. That was not a racing incident."}

Output:
{"speaker_ko": "막스 페르스타펜", "translation": "턴 4에서 무슨 일이 있었는지 얘기해야 할 것 같아요. 그건 레이싱 사고가 아니었어요.", "notes": null}
