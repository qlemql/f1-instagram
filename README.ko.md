# F1 Instagram — 기자회견 카드뉴스 자동화

[English](README.md) · **한국어**

> F1 기자회견을 한국어 인스타그램 캐러셀로 변환하는 자동화 파이프라인. 월 $10 Claude API 예산 한도 안에서 운영됩니다.

🇰🇷 타겟: 한국 F1 팬  
💰 예산: 월 $10 (Claude API 총 지출 하드캡)  
⚙️ 런타임: GitHub Actions (무료 티어)

---

## 무엇을 하나요

F1 그랑프리 주말마다 파이프라인이 다음을 수행합니다:

1. **수집** — FIA 기자회견 전문을 스크래핑 (`formula1.com`을 fallback으로)
2. **선별** — Claude Haiku로 드라이버별 Q&A에 점수를 매기고 인용할 만한 답변을 선택
3. **번역** — 선정된 Q&A를 한국어로 번역 (요약이 아닌 전문 번역)
4. **헤드라인 생성** — 드라이버별로 한 줄 커버 헤드라인 작성
5. **슬라이드 분할** — 번역문을 약 180자씩 슬라이드로 분할 (의도적으로 AI 미사용)
6. **렌더링** — 팀 컬러 테마를 적용한 인스타그램 캐러셀 카드(1080×1350)로 렌더링
7. **전달** — 결과를 텔레그램으로 받아 검토 후 인스타그램에 수동 업로드

최종 결과: 드라이버 1명당 캐러셀 게시물 1개. 팀 컬러, 한국어 번역, 인용할 만한 헤드라인 포함.

## 비용 엔지니어링 문제

순진한 구현은 모든 기자회견 발언에 Claude Sonnet을 호출합니다. 회기당 약 30개 발언 × 연간 23개 GP면 월 $10을 가뿐히 넘기고, 그 지출의 대부분은 흥미롭지 않은 발언에 낭비됩니다.

실제 파이프라인은 **Haiku 전용**이고, 비싼 연산은 결정론적 코드로 대체했습니다:

| 단계 | 무엇을 하나 | 왜 이 선택인가 |
|------|------------|--------------|
| 발언 점수 (1차) | Haiku, 발언 5개씩 배치 | 배치로 오버헤드 약 80% 감소 |
| 핵심 발언 선정 (2차) | Haiku, 드라이버당 1회 호출 | 드라이버 1명 = 게시물 1개로 스코프 |
| Q&A 번역 | Haiku, 전문 번역 | 번역은 Sonnet 품질 불필요 |
| 커버 헤드라인 | Haiku, 한 줄 생성 | 게시물당 짧은 호출 1회 |
| 슬라이드 분할 | **순수 Python, AI 미사용** | 결정론적이고 무료, 완벽하게 동작 |
| 이미지 렌더링 | Pillow, 헤드리스 브라우저 미사용 | 더 빠르고 무료 |

AI 대신 코드로 슬라이드를 분할한 것이 가장 큰 비용 절감 — 게시물당 약 17번의 LLM 호출이 될 뻔한 것을 `textwrap.wrap()` 한 번으로 대체했습니다.

## CostGuard

전용 `CostGuard` 모듈이 SDK 경계에서 예산을 강제합니다. 비용 체크 없이 통과하는 Claude 호출은 없습니다.

- 호출당 비용을 토큰 수 × 모델 가격표로 계산
- GP당 소프트 한도: `$0.10` (경고만, 차단 안 함)
- 월간 하드 한도: `$10.00` — `BudgetExceededError`를 발생시켜 이후 모든 호출 차단
- 경고 임계값: 누적 `$8.00` 도달 시 `MonthlyBudgetWarning` 발생
- 모든 호출은 `logs/{gp_name}_cost.jsonl`에 JSONL로 기록되어 사후 분석 가능

이 패턴은 자는 동안 사이드 프로젝트가 조용히 API 예산을 출혈하는 좌절감에서 나왔습니다. 무인 자동화에 하드캡은 타협 불가입니다.

## 카드 렌더링

순수 Pillow, 헤드리스 브라우저 미사용. 각 카드는:

- **팀 컬러**를 `team_colors.json`에서 사용 (2026 시즌 11개 팀 전부)
- **타이포그래피**: 임팩트는 Bebas Neue, 한국어 본문은 Pretendard
- **캐러셀 포맷**: 1080×1350, 게시물당 최대 18장 (커버 1 + 본문 17 + 출처 1)
- **디자인 토큰**을 `renderer/design_tokens.py`에서 관리하여 카드 간 일관된 간격·색상·타이포그래피 유지

## 왜 GitHub Actions인가

이 파이프라인은 이벤트가 가벼움 — 연간 약 23회 (레이스 주말 + 비시즌 테스트) 실행됩니다. 서버를 띄우는 건 낭비입니다. GitHub Actions가 주는 것:

- 오픈소스 한도 안에서 무료 컴퓨팅
- GP 주말에 맞춘 네이티브 cron 스케줄링
- API 키와 텔레그램 봇 토큰을 위한 무료 시크릿 관리
- 코드 리포와 런타임의 깔끔한 분리 — push로 배포

## 기술 스택

`Python 3.12` · `Anthropic Claude Haiku 4.5` · `Pillow` · `BeautifulSoup4` · `httpx` · `python-telegram-bot` · `GitHub Actions`

## 프로젝트 구조

```
scraper/        FIA + formula1.com 추출기와 URL 탐색
processor/      다단계 선별 파이프라인 + CostGuard
renderer/       Pillow 카드뉴스 생성기 + 디자인 토큰 + 팀 컬러
notifier/       검토 전달용 텔레그램 봇
prompts/v1/     버전 관리되는 Claude 프롬프트 (선별·번역·헤드라인)
config.py       모델, 콘텐츠 규칙, 예산 상수
main.py         end-to-end 오케스트레이터
```

## 설계 원칙

- **드라이버당 게시물 1개** — 독립적인 캐러셀 세트, 병렬화 가능
- **번역은 전문 번역**, 압축 금지 — 발언의 완결성이 중요
- **슬라이드 분할은 코드**, AI 아님 — 결정론적이고 무료
- **CostGuard는 필수** — 모든 API 호출은 이를 거침
- **프롬프트는 버전 관리** — `prompts/v1/` 아래 두어 반복 작업이 과거 실행을 깨지 않도록
